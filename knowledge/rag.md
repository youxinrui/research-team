# RAG 检索增强生成

RAG（Retrieval-Augmented Generation）在生成回答之前先从外部知识库检索相关内容，再把检索结果作为上下文交给大模型。它能让模型使用私有资料、降低幻觉，并在资料更新时无需重新训练模型。

典型流程包括：文档加载、文本分块、向量化、建立索引、查询检索、重排和生成。分块时通常按段落或标题切分，每块几百字，并保留一定重叠，避免上下文在边界处被截断。

检索有两类常用方法。BM25 属于稀疏检索，依赖词项匹配和词频统计，擅长精确关键词、专有名词和代码符号；向量检索把文本映射为稠密向量，擅长语义相似和同义表达。两者互补，混合检索通常能同时覆盖精确匹配和语义匹配。

融合两路结果常用 RRF（Reciprocal Rank Fusion）：分别对两路结果按排名计分，再相加排序，这样不需要把两种分数量纲强行对齐。也可以对分数归一化后加权求和，但 BM25 的原始分数依赖语料，跨查询并不稳定。

判断是否命中知识库时，应同时看语义相似度和词项重叠。如果最高相似度低于阈值，且没有足够的 BM25 词项命中，就应当认为知识库没有相关内容，转而调用网络搜索或其他工具，而不是强行使用低质量片段。
