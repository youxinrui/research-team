# 本地模型部署：Ollama 与 vLLM

本地部署模型适合隐私敏感、需要离线运行或希望控制成本的场景。常见工具包括 Ollama 和 vLLM。Ollama 安装简单，适合开发和单机使用；vLLM 面向高吞吐服务，支持连续批处理和 PagedAttention，适合多用户生产环境。

Ollama 拉取模型后会在本地启动服务，并提供 OpenAI 兼容端点，默认地址是 http://localhost:11434/v1。应用只需把 base_url 指向该地址、把模型名改成已拉取的模型，例如 qwen2.5 或 qwen3 系列，就能复用现有 OpenAI SDK 代码。

量化能降低显存占用。GGUF 是常见的本地量化格式，按位数分为 Q4、Q5、Q8 等，位数越低显存越省、精度损失越大。选择量化级别时要结合显存容量、上下文长度和任务对精度的要求做实测。

本地模型与云端 API 的取舍在于：本地没有按 token 计费，但需要显卡和运维；云端免运维、模型能力通常更强，但有网络依赖和成本。工程上应通过配置切换模型端点，而不是把供应商写死在代码里。
