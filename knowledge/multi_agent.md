# 多智能体系统概述

多智能体系统（Multi-Agent System, MAS）由多个具备独立角色、提示词和工具的智能体组成，通过分工协作完成单个智能体难以处理的复杂任务。与单智能体相比，多智能体把任务拆解给不同角色，降低单个上下文的负担，也便于分别优化每个环节。

常见协作架构有四种。Supervisor（中心调度者）模式由一个管理智能体分派任务给专家并汇总结果；Handoff（分诊交接）模式由入口智能体判断后将对话转交给专家接管；Swarm（集群）模式允许智能体之间平级动态转接；层级式架构则在管理者和工作者之间再加入一层子管理者。

在工程实现中，agent 之间的协作不应依赖自由对话，而应通过共享状态传递结构化数据。每一步只更新状态中的特定字段，例如资料列表、大纲、草稿和审校结果，这样流程可追踪、可测试，也避免上下文在多次转述中丢失。

多智能体的代价是成本和延迟成倍增长，并且容易出现委托循环和错误传播。因此必须设置最大轮次、返工上限和明确的终止条件。对于任务边界清晰的场景，单个智能体配合工具往往就够了，多智能体只在子任务确实需要隔离上下文或独立职责时才划算。
